# 그래프 및 참고 이미지

프로젝트에서 생성한 EDA 그래프 11개와 평가 그래프 2개를 PNG로 보관합니다. `src/reporting.py`의 공통 그래프 함수가 저장하며 노트북과 main.py에서 같은 이름을 사용합니다. 같은 이름은 최신 실행 이미지로 덮어씁니다.

- `eda_*.png`: 수명·용량·ΔQ·상관·변환·배치·프로토콜 분석.
- `model_*.png`: 구성별 성능과 Batch2 예측.

이 파일들은 GitHub 문서 표시를 위해 Git에 포함할 수 있습니다. 외부 참고 이미지를 추가할 때는 원문 링크·출처·이용 조건을 이 문서에 기록합니다. 현재는 프로젝트에서 직접 생성한 그래프만 들어 있습니다.
